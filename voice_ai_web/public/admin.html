🧩 Agent types & templates

Users pick a type and a template when they create an agent. Agents use the template live, so a change here reaches every agent using it on its next call. In any text, {agent} is the agent's name, {owner} who it works for and {org} the organization; a part in [[ … ]] is left out when a value inside it is empty.
